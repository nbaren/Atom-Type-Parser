Hi! This is a quick project I built to parse through the PDBbind+ dataset and extract important information. 
It collects data on the frequency of the atom types present in the data set, as well as the number of unique
ligands and proteins.

Unfortunately, this repo doesn't contain the entire massive dataset, so you're going to just have to look at the results
graphs and trust that I did my work properly.

I learned a lot in this project about file parsing and file structure, as well as different Python libraries 
optimized for biophysics and computational biology work!
